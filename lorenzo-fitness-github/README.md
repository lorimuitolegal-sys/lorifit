# Lorenzo Fitness

App de treinos (PWA) pronto para o GitHub Pages. Funciona no computador e no celular.

## Como publicar no GitHub Pages
1. Crie uma conta em https://github.com (se ainda não tiver).
2. Clique em **New repository**, dê um nome (ex.: `lorenzo-fitness`), deixe **Public** e crie.
3. Clique em **uploading an existing file** e envie TODOS os arquivos desta pasta (inclusive `.nojekyll`). Clique em **Commit changes**.
4. Vá em **Settings > Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e clique em **Save**.
5. Aguarde 1–2 minutos. O endereço será `https://SEU-USUARIO.github.io/lorenzo-fitness/`.

## Instalar no celular
- **Android (Chrome):** abra o endereço > menu ⋮ > **Instalar app**.
- **iPhone (Safari):** abra o endereço > botão compartilhar > **Adicionar à Tela de Início**.

## Atualizar depois
Edite/substitua o arquivo no repositório e faça commit. O app busca a versão nova sempre que houver internet.

## Observação
Marcações e registros ficam salvos só no navegador do aparelho (não sincronizam entre celular e computador).
